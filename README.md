# bot_TG_Foxy_Log

Telegram-бот для регистрации и ведения лидов в Google Таблице. Менеджеры создают карточки, пропускают пока неизвестные поля, находят лидов и дозаполняют их позднее. Бот автоматически фиксирует имя, Telegram-ник и постоянный Telegram ID ответственного.

## Возможности первого этапа

- добавление лида пошагово;
- сохранение неполной карточки;
- раздел «Требуют уточнения»;
- просмотр последних лидов;
- поиск по ID, имени, контактам, городу и товару;
- редактирование отдельных полей;
- изменение статуса;
- предупреждение о дублирующемся контакте;
- автоматическая фиксация менеджера и его `@username`;
- менеджер видит только свои лиды, руководитель — все;
- Google Таблица является единым источником данных.
- формирование КП по Excel-шаблону;
- тарифный калькулятор для стандартного товара и согласованных категорий КГТ;
- отправка готового КП менеджеру в Telegram;
- загрузка КП на Google Drive и сохранение ссылки в карточке лида.

## Требования

- Node.js 20 или новее;
- Telegram-бот, созданный через `@BotFather`;
- Google Таблица, импортированная из подготовленного Excel-шаблона;
- сервисный аккаунт Google с доступом редактора к таблице.

## Настройка Google Таблицы

1. Загрузите `Шаблон_таблицы_лидов.xlsx` в Google Drive и откройте как Google Таблицу.
2. В Google Cloud создайте проект и включите **Google Sheets API** и **Google Drive API**.
3. Создайте сервисный аккаунт и JSON-ключ.
4. В JSON найдите `client_email`.
5. Откройте доступ к таблице для этого email с ролью **Редактор**.
6. Скопируйте ID таблицы из адреса между `/d/` и `/edit`.
7. Не переименовывайте лист `Лиды` и его заголовки после подключения бота.

При первом запуске бот автоматически добавит справа столбцы КП: номер, дата, ссылка, суммы и статус.

## Формирование КП

В карточке лида нажмите **«Создать КП»**. Бот запросит тип товара и параметры расчёта, сформирует Excel, отправит его менеджеру, загрузит в указанную папку Google Drive и запишет ссылку в строку лида.

Для стандартного товара используются диапазоны:

| Единиц в месяц | Обработка | Приёмка | Хранение |
|---:|---:|---:|---:|
| 1–1 000 | 100 ₽ | 5 ₽ | 90 ₽ |
| 1 001–1 499 | 85 ₽ | 5 ₽ | 80 ₽ |
| 1 500–2 500 | 65 ₽ | 4 ₽ | 75 ₽ |
| 2 501–5 000 | 40 ₽ | 3 ₽ | 75 ₽ |
| 5 001–7 000 | 35 ₽ | 3 ₽ | 75 ₽ |

Все ставки указаны без НДС. Сумма с НДС рассчитывается по ставке 22%. Объём свыше 7 000 единиц требует индивидуального расчёта.

Для загрузки КП создайте папку на Google Drive, откройте её сервисному аккаунту с правом редактора и укажите ID папки в `GOOGLE_DRIVE_FOLDER_ID`.

## Telegram ID сотрудников

Чтобы узнать Telegram ID менеджеров, можно использовать бота `@userinfobot`. Добавьте ID сотрудников в `ALLOWED_TELEGRAM_IDS`, а ID руководителей — в `ADMIN_TELEGRAM_IDS`.

Если у менеджера нет публичного `@username`, бот сохранит текст «Ник не установлен» и постоянный Telegram ID.

## Запуск без Docker

```bash
cp .env.example .env
npm install
npm test
npm start
```

Заполните `.env` перед запуском. JSON-ключ положите в `credentials.json`. Эти файлы исключены из Git и не должны попадать в репозиторий.

## Запуск через Docker

```bash
cp .env.example .env
docker compose up -d --build
docker compose logs -f leads-bot
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `GOOGLE_SPREADSHEET_ID` | ID Google Таблицы |
| `GOOGLE_SHEET_NAME` | Название листа, по умолчанию `Лиды` |
| `GOOGLE_SERVICE_ACCOUNT_FILE` | Путь к JSON-ключу |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | Альтернатива: JSON-ключ одной строкой |
| `ALLOWED_TELEGRAM_IDS` | ID всех сотрудников через запятую |
| `ADMIN_TELEGRAM_IDS` | ID руководителей через запятую |
| `TIMEZONE` | Часовой пояс дат, по умолчанию `Europe/Moscow` |
| `GOOGLE_DRIVE_FOLDER_ID` | ID папки для сохранения сформированных КП |
| `DRIVE_SHARE_WITH_LINK` | Создавать ссылку для просмотра файла |
| `QUOTE_TEMPLATE_FILE` | Путь к Excel-шаблону КП |

## Безопасность

- токен Telegram и ключ Google хранятся только в `.env`/`credentials.json` на сервере;
- доступ к боту закрыт списком Telegram ID;
- секреты исключены через `.gitignore`;
- права сервисного аккаунта можно ограничить одной таблицей.

## Структура таблицы

Бот ожидает исходные 15 столбцов в точном порядке из Excel-шаблона: от `ID лида` до `Дата изменения`. Шесть столбцов КП добавляются автоматически. При несовпадении исходных заголовков бот остановится с понятной ошибкой, чтобы не записать данные не в те столбцы.
